#  Stock Price Movement Analysis of Tech Giants

##  Overview
This project analyzes stock price data of major tech companies using Exploratory Data Analysis (EDA).

##  Features
- Data cleaning & preprocessing
- Moving averages (7-day, 30-day)
- Volatility analysis
- Volume analysis
- Multi-company comparison
- Correlation heatmap
- Cumulative return analysis

##  Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn

##  Key Insights
- Strong long-term growth in tech stocks
- Increasing volatility in recent years
- Different companies show varying growth rates
- Volume trends indicate changing market behavior

## Dataset
- Historical stock price data (CSV format)
